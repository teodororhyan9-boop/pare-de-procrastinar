
# Pare de Procrastinar

Plataforma interativa de estudos desenvolvida para ajudar estudantes a organizar o aprendizado e combater a procrastinação.

## Sobre o projeto

O Pare de Procrastinar é um projeto web que reúne conteúdos educativos, videoaulas e desafios interativos em um ambiente simples e acessível.

O objetivo é incentivar hábitos de estudo mais produtivos e facilitar o acesso ao conhecimento.

## Tecnologias utilizadas

- HTML5
- CSS e Tailwind CSS
- JavaScript
- Supabase — autenticação de usuários
- Netlify — hospedagem do site
- GitHub — versionamento do código

## Funcionalidades

- Cadastro e login de usuários
- Acesso a videoaulas
- Conteúdos sobre procrastinação
- Interface adaptada para diferentes dispositivos
- Ambiente de estudos interativo
